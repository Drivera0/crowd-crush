How it works

Math detects. AI explains.

Phones

A web page from one QR code. Ten motion readings a second.

One Go server

Clock sync, neighbour comparison every 250 ms, density, position estimate.

People

Staff: one sentence and one action, read aloud. Sign and zone lights. Each phone: which way to move.

Gemini writes the sentence and reads floor plans. ElevenLabs speaks it. If either is down, the alarm still fires with a template sentence.

The alarm is signal processing: cross-correlation between neighbours and density from clustering. Every outside service can fail and the alarm still fires.
